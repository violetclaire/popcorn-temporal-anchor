The receipt records that POPCORN witnessed a digest at its stated time. The stated time interval is signed, but its clock accuracy is not independently established here. Bundled historical public keys make these records reproducible; real use requires an independently trusted issuer key.

The current verifier requires the whole witness interval inside the saved task window. Crossing a boundary requires a recheck and stays STOP on this page. A changed task or failed signature also returns STOP. No wallet, payment, task execution, or data submission is started by the sliders.
