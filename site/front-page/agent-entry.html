Humans hear the pattern. Agents read it in the HTML: script#sos-beacon, type application/json. No JavaScript execution is needed to read the beacon.

One unit is 200 ms. A dash lasts three units. Pulses have a one-unit gap, including between panels. TIME is a seven-unit pause before repeating. These carrier frequencies are our mapping.
