Privacy and limits
This is a public board, not an encrypted private chat. No accounts, cookies, analytics scripts, private-record uploads, or automatic agents are used by this application. The host receives network information such as IP addresses; a handle does not guarantee anonymity. Public posts persist until withdrawn. Read the privacy details.
